# 小学数学个性化练习与双人 PK 平台

本项目面向小学生、教师和管理员，当前聚焦人教版小学数学计算类知识点。所有练习、作业、拍照批改和 PK 作答都使用题库中已审核启用的固定题目，并汇入同一份学习档案。

> 当前开发顺序：优先完成双人实时 PK、OCR 批改闭环和教师/管理员体验；单人及团队闯关暂缓，不作为当前版本完成条件。

## 核心闭环

```text
自主练习 / 教师作业 / OCR 拍照批改 / 双人 PK
    → 可信判题
    → 错题与知识点掌握度更新
    → 生成针对性巩固推荐
    → 再次练习验证
```

## 当前业务能力

### 学生

- 按年级、学期和知识点完成普通或限时练习。
- 接收教师统一作业或分层作业，提交后统一查看批改反馈。
- 在微信小程序中创建好友房、输入房间码或随机匹配，完成双人限时同题 PK。
- 拍照上传整页作业，查看 OCR 进度，确认、修正或忽略低可信识别题目。
- 查看错题、掌握度、巩固推荐、PK 历史、积分、经验和段位。

### 教师

- 管理本人班级和学生，布置统一或分层作业，查看学生提交与成绩。
- 直接从有效班级学生名单选择学生，无需手工查找用户 ID。
- 查看本人班级学生的学习档案、错题、薄弱知识点和巩固建议。
- 查看班级平均正确率、完成率、薄弱知识点、高频错题、错因、趋势和异常学生提醒，并下钻到单个学生。
- 从薄弱知识点直接为全班生成针对练习，或预填并创建班级作业。
- 在 OCR 工作台按班级、学生、状态和时间筛选任务，对照原图、切题图、识别结果和标准题目完成复核。
- 批量通过高可信识别结果、重试失败任务，并查看完整修改历史和处理人。

### 管理员

- 管理账号、角色、权限、内容模块、知识点、固定题目和错因字典。
- 从学生目录直接查看全平台学生学情、推荐与拍照批改任务。
- 查看用户、班级、题库、学习、OCR 和 PK 的跨服务运营指标。
- 处理题目错误反馈，可在确认问题后联动下架题目。
- 全局检索操作日志和关键数据变更，按操作人、来源、动作、对象和时间过滤。
- 处理 OCR 低可信结果并保留复核前后快照和复核说明。

## 双人 PK

- 支持好友房和随机匹配两种组局方式，房主可配置知识点、难度、题量和时限。
- 两名学生使用同一组固定题目，各自按顺序作答；前端实时轮询双方进度并显示倒计时、比分和连击。
- 服务端负责幂等答题、计分、超时结算、胜负、积分、经验和段位更新。
- 游戏服务通过事务发件箱和 RabbitMQ 将逐题结果可靠同步到学习服务；PK 错题同样进入错题、掌握度与巩固推荐闭环。

单人关卡、关卡解锁和团队闯关的数据结构目前保留，但不继续扩展相关前端和运营能力。

## OCR 拍照批改

系统已完成 OCR 业务闭环和外部识别工作器接入契约：

1. 学生通过小程序上传私有图片并创建拍照批改任务。
2. OCR 工作器使用内部服务令牌轮询 `GET /internal/learning/photo-marking/pending`。
3. 工作器调用 `POST /internal/learning/photo-marking/{taskId}/start` 领取任务，再通过 `GET /internal/files/{fileId}?ownerId={studentId}` 校验所有权并读取私有原图。
4. 工作器完成切题、文字识别和固定题库匹配后，向 `POST /internal/learning/photo-marking/{taskId}/recognition` 回传结构化结果；无法处理时回调 `/failure`。
5. 可信度不低于 0.85 且成功匹配固定题目的结果自动判题；其余题目进入学生/教师/管理员复核。
6. 确认后的答案统一更新答题记录、错题、掌握度和巩固推荐，并保留人工复核审计快照。

仓库不绑定某一家 OCR 厂商；部署时需单独配置实现上述内部契约的 OCR 工作器和供应商凭据。未配置工作器时，任务会安全停留在“等待识别”，不会生成伪造结果。

## 业务边界

- 聚焦小学数学基础计算，不扩展为全学科教务平台。
- 家长和开发者开放平台暂不纳入当前版本。
- 题目只来自数据库中的已审核固定题库，不调用大模型生成题目。
- 教师只能访问本人有效班级学生；管理员可访问全部学生。
- 单人/团队闯关暂缓，当前游戏体验只聚焦双人 PK。

## 工程结构

### 后端

- Java 21、Spring Boot 4、Spring Cloud 2025、PostgreSQL、MyBatis-Plus、Sa-Token、RabbitMQ、Nacos。
- 多模块微服务包含 Gateway、用户、内容、学习、教学、游戏、文件、通知和审计服务。
- 游戏与教学跨服务写入均使用事务发件箱，避免本地事务成功而消息丢失。

### 前端

- Vue 3 + TypeScript + TDesign Vue Next 管理端，覆盖学生练习、教师教学、学情查看、内容和系统管理、OCR 复核。
- 原生 TypeScript 微信小程序，覆盖练习、作业、学习档案、OCR 上传与确认、双人 PK。
