# 小学数学智能学习与游戏对战平台

本项目是一套面向小学生、教师和管理员的通用型小学数学学习平台。第一版围绕“练习、批改、诊断、推荐、验证”建立完整学习闭环，并加入游戏闯关、一对一对战、组队对战以及面向第三方应用的开放平台功能。

系统不针对某一所学校定制。学生可以不加入学校或班级，直接选择年级、学期和教材版本使用核心学习功能；加入班级后，可进一步接收教师作业、查看班级学习安排并参与班级活动。

> 当前 README 只说明第一版业务功能范围，不展开技术架构、认证方案、数据库设计或部署方式。详细业务说明见 [系统功能总结](./文档/系统功能总结.docx)。

## 第一版业务角色

### 学生

- 独立注册并使用学习、练习、拍照辅助批改、错题、推荐、闯关和公共对战功能。
- 可选加入学校和班级；加入后接收教师作业、训练计划和班级活动。
- 查看个人作答记录、错题、知识点掌握度、学习报告、游戏成长和对战记录。

### 教师

- 管理本人负责范围内的班级和学生。
- 创建并发布统一作业、分层作业和训练计划。
- 查看学生和班级的完成情况、错题分布及薄弱知识点。
- 复核低可信批改结果，组织班级闯关或对战活动。

### 管理员

- 维护学校、年级、班级和用户等基础业务数据。
- 维护教材版本、教材章节、知识点、题库、答案、难度和错因分类。
- 配置练习、推荐、闯关、积分、排行榜和对战等业务规则。
- 管理第三方应用接入和开放平台业务使用情况。

家长不作为第一版独立业务角色；第三方开发者通过开放平台的应用主体接入，不增加新的人工业务角色。

## 核心学习闭环

```text
选择或生成练习
    → 在线作答或拍照提交
    → 辅助批改与结果确认
    → 形成错因记录
    → 更新知识点掌握度
    → 推荐针对性练习
    → 再次验证
```

练习、教师作业、单人闯关和对战产生的作答记录都会进入学生学习档案，用于后续错因分析、掌握度更新和个性化推荐。

## 第一版主要业务模块

### 1. 学生与学习档案

- 维护学生年级、学期、默认教材版本等学习信息。
- 学校和班级为可选组织关系，未加入组织时仍可使用核心学习功能。
- 汇总练习、作答、错题、掌握度、推荐、作业、闯关和对战记录。

### 2. 教材与知识体系

- 教材版本包含多个教材章节，教材章节覆盖相应知识点。
- 同一知识点可以映射到不同教材版本的不同章节。
- 题目通过知识点与教材内容建立联系，支持多教材适配。

### 3. 题库与出题

- 维护题干、题型、标准答案、解析、难度、知识点和适用范围。
- 支持单选、填空、判断、口算、竖式计算和应用题等常见题型。
- 支持教师选题、规则组题和个性化组题。

### 4. 个性化口算与常规练习

- 根据学生年级、近期错题、答题速度和知识点掌握度生成口算练习。
- 支持专项练习、限时练习以及自定义知识点、题型、难度和题量。
- 保存每次作答的答案、开始时间、用时、正确性和得分。

### 5. 拍照识别与辅助批改

- 支持拍摄或上传作业图片，完成题目切分、内容识别和答案提取。
- 对支持的题型判断正误；对结构明确的题型定位部分步骤错误。
- 低可信结果提示学生确认或进入教师复核，避免错误结果直接写入学习档案。
- 第一版不承诺识别所有手写应用题的完整推理过程，也不以辅助批改替代教师判断。

### 6. 错因诊断、掌握度与个性化推荐

- 按知识点和错误类型归纳错题，保存错误位置、错因说明和复核结果。
- 综合正确率、答题速度、题目难度、练习频率和最近练习时间更新掌握度。
- 针对薄弱知识点生成相似题、变式题和复习题，并通过再次练习验证效果。

### 7. 教师作业与学习报告

- 创建作业并设置题目、分值、班级、开始时间和截止时间。
- 支持统一作业和按照学生掌握情况生成的分层作业。
- 查看完成情况、得分、正确率、错题分布、知识点掌握情况和阶段趋势。
- 根据报告制定并发布后续训练计划。

### 8. 游戏闯关与学习激励

- 单人模式统一称为“单人闯关”。
- 学生主动发起闯关，系统根据年级、知识点和掌握度生成题目。
- 第一版默认每关 10 题，并设置总答题时限；规定时间内完成且正确率达到 80% 判定成功。
- 成功后增加积分和经验并解锁下一关；失败保留记录，展示错题和错因，完成巩固后可再次挑战。
- 支持积分、经验、等级、徽章、成就、连续学习、每日任务和排行榜。

### 9. 一对一与组队对战

- 一对一对战支持系统匹配、同学邀请和房间对战。
- 双方使用相同题目或同知识点、同难度的等价题目，以正确题数为主、用时作为同分判定依据。
- 组队对战支持队伍创建、加入、退出、成员管理和相同人数队伍匹配。
- 团队成绩汇总队员得分，同时保留个人正确题数、得分和贡献排名。
- 对战结果进入个人学习档案，用于后续薄弱知识点分析和推荐练习。

### 10. 平台运营管理

- 管理学校、年级、班级以及学生入班、离班等组织关系。
- 管理教材、章节、知识点、题型、题目、答案、难度和错因分类。
- 管理练习、推荐、闯关、成长、排行榜和对战规则。
- 查看异常作答、低可信批改、教师复核、对战异常和业务运营统计。

### 11. 开放平台

开放平台是第一版正式业务模块。第三方学校系统、教育应用或学习工具可以申请接入，在审核通过的能力范围内使用平台服务，并查看自身的使用记录和额度情况。

第一版计划开放以下业务能力：

- 按年级、知识点、题型、难度和题量查询题目或生成练习。
- 提交题目和学生答案，获得答案校验、辅助批改和解释结果。
- 提交作业图片，获得题目切分、内容识别和处理状态。
- 查询错误分类、知识点掌握度和学习变化。
- 获取个性化推荐知识点、推荐题目和训练计划。
- 针对明确的题目、答案和知识点生成适合小学生理解的辅助讲解。

开放平台同时提供第三方应用资料提交、接入审核、能力申请、使用额度、调用记录和异常查询等业务功能。

## 第一版主要业务流程

1. **独立学习：**学生选择年级、学期和教材版本，完成练习、批改、错因诊断、个性化推荐和再次验证。
2. **班级作业：**教师创建并发布作业，学生提交，系统统计，教师复核并发布后续训练。
3. **单人闯关：**学生选择关卡，系统生成题目，限时作答，完成结算、奖励、解锁或再次挑战。
4. **学习对战：**学生或队伍发起匹配，进入房间，公平出题，实时计分，完成结算并写入学习记录。
5. **开放调用：**第三方应用申请接入，管理员审核能力范围，应用调用业务能力并查询处理结果。

## 第一版业务边界

- 系统面向多学校和独立学生，不针对某一所学校单独设计。
- 学校和班级不是学生使用核心学习功能的前置条件。
- 家长不作为第一版独立业务角色。
- 面向学生的智能能力用于识别、解释、诊断和推荐，不提供无限制开放聊天，也不自动代写作业。
- 教师发布的作业、训练计划和需要教学判断的批改结果保留教师确认环节。
- 本 README 只描述第一版业务范围，技术实现另行编写技术文档。
