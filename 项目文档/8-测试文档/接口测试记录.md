## 2. 测试记录模板

每次测试按以下格式填写：

| 字段 | 说明 |
|------|------|
| 测试编号 | 唯一标识（如 TEST-001） |
| 接口名称 | 接口功能名称 |
| 接口地址 | 完整的接口 URL |
| 请求方法 | GET/POST/PUT/DELETE |
| 测试时间 | 测试执行时间 |
| 测试人员 | 执行测试的人员 |
| 请求参数 | 实际发送的参数（JSON/Query） |
| 预期结果 | 期望的响应结果 |
| 实际结果 | 实际收到的响应 |
| 是否通过 | ✅ 通过 / ❌ 失败 |
| 备注 | 问题描述或特殊说明 |
