## 2. 字段设计

### 2.1 t_user 字段详情

| 字段名 | 数据类型 | 长度/精度 | 是否可空 | 默认值 | 说明 |
|--------|----------|-----------|----------|--------|------|
| `id` | BIGINT UNSIGNED | — | NOT NULL | AUTO_INCREMENT | 主键，自增 |
| `username` | VARCHAR | 50 | NOT NULL | — | 用户名，全局唯一，用于登录 |
| `password` | VARCHAR | 255 | NOT NULL | — | BCrypt 加密后的密码，固定 60 字符，预留 255 |
| `email` | VARCHAR | 100 | NULL | NULL | 邮箱地址，可选，唯一（非空时唯一） |
| `phone` | VARCHAR | 20 | NULL | NULL | 手机号码，可选，唯一（非空时唯一） |
| `avatar` | VARCHAR | 255 | NULL | NULL | 头像图片 URL（MinIO 存储路径） |
| `status` | TINYINT(1) | — | NOT NULL | 1 | 账号状态：0-禁用，1-启用 |
| `deleted` | TINYINT(1) | — | NOT NULL | 0 | 逻辑删除：0-未删除，1-已删除 |
| `create_time` | DATETIME | — | NOT NULL | CURRENT_TIMESTAMP | 注册时间 |
| `update_time` | DATETIME | — | NOT NULL | CURRENT_TIMESTAMP | 最后更新时间，自动维护 |

### 2.2 索引设计

| 索引名 | 索引类型 | 字段 | 说明 |
|--------|----------|------|------|
| PRIMARY | 主键索引 | `id` | 主键自增 |
| `uk_username` | 唯一索引 | `username` | 用户名全局唯一 |
| `uk_email` | 唯一索引 | `email` | 邮箱唯一（允许 NULL） |
| `uk_phone` | 唯一索引 | `phone` | 手机号唯一（允许 NULL） |
| `idx_status_deleted` | 普通索引 | `status`, `deleted` | 覆盖状态查询，加速过滤 |

> **说明**：MySQL 唯一索引中，`NULL` 值不算重复，因此邮箱和手机号设置唯一索引时允许多条 `NULL` 记录共存。

## 3. 建表 SQL

```sql
-- 切换到用户服务数据库
USE user_db;

-- 创建用户表
CREATE TABLE IF NOT EXISTS `t_user`
(
    `id`          BIGINT UNSIGNED  NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `username`    VARCHAR(50)      NOT NULL COMMENT '用户名，全局唯一',
    `password`    VARCHAR(255)     NOT NULL COMMENT 'BCrypt加密密码',
    `email`       VARCHAR(100)     NULL     DEFAULT NULL COMMENT '邮箱地址',
    `phone`       VARCHAR(20)      NULL     DEFAULT NULL COMMENT '手机号码',
    `avatar`      VARCHAR(255)     NULL     DEFAULT NULL COMMENT '头像URL（MinIO路径）',
    `status`      TINYINT(1)       NOT NULL DEFAULT 1 COMMENT '账号状态：0-禁用，1-启用',
    `deleted`     TINYINT(1)       NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    `create_time` DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间',
    `update_time` DATETIME         NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后更新时间',

    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`),
    UNIQUE KEY `uk_email` (`email`),
    UNIQUE KEY `uk_phone` (`phone`),
    INDEX `idx_status_deleted` (`status`, `deleted`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4
  COLLATE = utf8mb4_unicode_ci
  COMMENT = '用户基本信息表';
```

## 4. 对应 Java 实体类

```java
package xyz.jiayuhan.user.entity;

import com.baomidou.mybatisplus.annotation.*;
import lombok.Data;
import java.time.LocalDateTime;

/**
 * 用户实体类
 */
@Data
@TableName("t_user")
public class User {
    
    /**
     * 主键ID（MyBatis-Plus 自动识别）
     */
    @TableId(type = IdType.AUTO)
    private Long id;
    
    /**
     * 用户名
     */
    private String username;
    
    /**
     * BCrypt 加密密码（不返回给前端）
     */
    private String password;
    
    /**
     * 邮箱
     */
    private String email;
    
    /**
     * 手机号
     */
    private String phone;
    
    /**
     * 头像 URL
     */
    private String avatar;
    
    /**
     * 账号状态：0-禁用，1-启用
     */
    private Integer status;
    
    /**
     * 逻辑删除标记（MyBatis-Plus 自动处理）
     */
    @TableLogic
    private Integer deleted;
    
    /**
     * 创建时间（INSERT 时自动填充）
     */
    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createTime;
    
    /**
     * 更新时间（INSERT 和 UPDATE 时自动填充）
     */
    @TableField(fill = FieldFill.INSERT_UPDATE)
    private LocalDateTime updateTime;
}
```

## 5. 对应 DTO/VO 设计

### 5.1 用户注册 DTO

```java
package xyz.jiayuhan.user.dto;

import jakarta.validation.constraints.*;
import lombok.Data;

/**
 * 用户注册请求 DTO
 */
@Data
public class UserRegisterDTO {
    
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度为3-20个字符")
    @Pattern(regexp = "^[a-zA-Z0-9_]+$", message = "用户名只能包含字母、数字和下划线")
    private String username;
    
    @NotBlank(message = "密码不能为空")
    @Size(min = 6, max = 20, message = "密码长度为6-20个字符")
    private String password;
    
    @Email(message = "邮箱格式不正确")
    private String email;
    
    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式不正确")
    private String phone;
}
```

### 5.2 用户信息 VO（响应对象）

```java
package xyz.jiayuhan.user.vo;

import lombok.Data;
import java.time.LocalDateTime;

/**
 * 用户信息响应 VO（不含敏感字段）

    private String username;
    private String email;      // 脱敏处理（如：abc***@qq.com）
    private String phone;      // 脱敏处理（如：138****1234）
    private String avatar;
    private Integer status;
    private LocalDateTime createTime;
}
```
