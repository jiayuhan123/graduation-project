# 基础服务部署说明

## 1. 当前部署范围

- `gateway`：默认端口 `10000`
- `user-service`：默认端口 `8001`
- Nacos、Redis、PostgreSQL 和 RabbitMQ：由 `docker-compose.yaml` 提供本地环境

旧选题的业务服务和数据库不属于当前部署范围。新服务应在选题和领域模型确认后再加入。

## 2. 前置条件

1. 安装 Java 21 和带 Compose 插件的 Docker。
2. 启动 Docker Compose 中的基础中间件。
3. PostgreSQL 只需准备空的 `user_db`，Flyway 自动建表和升级。
4. 通过环境变量或 Nacos 配置数据源、Redis、Token 等参数。
5. 密码、Access Key 和密钥不得提交到仓库。

## 3. 推荐启动顺序

1. PostgreSQL、Redis、RabbitMQ。
2. Nacos，并确认健康状态。
3. `user-service`，确认已注册到 Nacos。
4. `gateway`，确认 `/api/user/**` 可以正确转发。

## 4. 配置原则

- 本地、测试和生产环境使用不同配置集。
- 生产环境通过环境变量或配置中心注入敏感配置。
- 服务地址优先使用服务发现，不写死具体实例 IP。
- 对网关、用户服务和中间件配置健康检查与日志轮转。
- 新业务服务部署前补充端口、数据库、路由、资源限制和回滚方案。

## 5. 部署验证

- Maven 工程能够完成构建或校验。
- Nacos 中可见 `gateway` 与 `user-service` 健康实例。
- Flyway 成功执行且用户/RBAC 表完整。
- 注册、登录、个人资料和管理权限请求能通过网关到达用户服务。
- Token 会话能够写入 Redis。
- 禁用、改密和角色调整后目标会话立即失效。
