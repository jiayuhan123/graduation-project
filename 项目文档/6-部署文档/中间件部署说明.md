# 中间件部署说明

根目录 `docker-compose.yaml` 是本地中间件唯一编排来源，包含 PostgreSQL、Redis、Nacos、RabbitMQ 和 Jenkins。阿里云 OSS 是外部托管资源，不在 Compose 内运行。

```powershell
docker compose config --quiet
docker compose up -d postgres redis nacos rabbitmq
docker compose ps
```

| 组件 | 本地地址 | 开发凭据 |
| --- | --- | --- |
| PostgreSQL | `localhost:5432` | `root / 111111` |
| Redis | `localhost:6379` | 密码 `111111` |
| Nacos 控制台 | `http://localhost:8847` | 以 Compose 配置为准 |
| RabbitMQ | `localhost:5672` | `root / 111111` |
| RabbitMQ 控制台 | `http://localhost:15672` | `root / 111111` |

PostgreSQL 空数据目录首次启动会执行 `deploy/postgres/init/01-create-service-databases.sql`，创建四个服务数据库。如果 `data/postgres` 已存在，初始化脚本不会再次运行，应手工创建缺失数据库，不能为了重跑脚本删除已有数据。

RabbitMQ 使用持久化 Exchange/Queue，数据位于 `data/rabbitmq`。升级或清理前先备份；死信队列应在修复根因后有控制地重放，禁止无分析清空。

生产环境需使用独立账号、最小权限、强密码、TLS、备份、日志轮转、健康检查与监控告警。镜像版本应固定并经过验证。
