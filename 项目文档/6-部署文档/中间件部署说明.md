## 1. 概述

本项目所有中间件通过 **Docker Compose** 统一编排部署，一键启动。部署目录结构如下：

```
~/graduation-project/middleware/
├── docker-compose.yaml      # Docker Compose 编排文件
├── mysql/
│   ├── conf/               # MySQL 自定义配置
│   └── data/               # MySQL 数据持久化（Volume）
├── redis/
│   └── conf/               # Redis 配置文件
├── nacos/
│   └── logs/               # Nacos 日志
├── rabbitmq/
│   └── data/               # RabbitMQ 数据持久化
└── minio/
    └── data/               # MinIO 文件持久化
```

## 3. Docker Compose 配置文件

```yaml
version: '3.8'

services:
  # =========================================================================
  # 1. MySQL (业务数据库) - 升级为最新的 8.4 LTS 长期支持版
  # =========================================================================
  mysql:
    image: mysql:8.4
    container_name: micro-mysql
    restart: always
    mem_limit: 256m
    environment:
      MYSQL_ROOT_PASSWORD: "111111"
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    volumes:
      - ./data/mysql/db:/var/lib/mysql
    command: 
      --mysql-native-password=ON
      --character-set-server=utf8mb4
      --collation-server=utf8mb4_general_ci
      --performance_schema=OFF
      --innodb_buffer_pool_size=64M
      --innodb_log_buffer_size=8M
      --max_connections=50
    networks:
      - micro-net

  # =========================================================================
  # 2. Redis 缓存 - 升级为最新的 8.0 极速版
  # =========================================================================
  redis:
    image: redis:8.0
    container_name: micro-redis
    restart: always
    mem_limit: 128m
    command: >
      redis-server 
      --requirepass 111111 
      --appendonly yes 
      --maxmemory 96mb 
      --maxmemory-policy allkeys-lru
    ports:
      - "6379:6379"
    volumes:
      - ./data/redis:/data
    networks:
      - micro-net

  # =========================================================================
  # 3. Nacos 注册 & 配置中心 - 升级为最新的 3.2.2 版本
  # =========================================================================
  nacos:
    image: nacos/nacos-server:v3.2.2
    container_name: micro-nacos
    restart: always
    mem_limit: 512m
    environment:
      MODE: standalone
      JVM_XMS: 256m
      JVM_XMX: 256m
      JVM_XMN: 128m
      NACOS_AUTH_IDENTITY_KEY: nacos_identity_project
      NACOS_AUTH_IDENTITY_VALUE: nacos_identity_value_111111
      NACOS_AUTH_TOKEN: SecretKey012345678901234567890123456789012345678901234567890123456789
      TZ: Asia/Shanghai
    ports:
      - "8848:8848"  # API 端口
      - "8847:8080"  # 3.x 独立控制台端口
      - "9848:9848"
      - "9849:9849"
    volumes:
      - ./data/nacos/logs:/home/nacos/logs
      - ./data/nacos/data:/home/nacos/data
    networks:
      - micro-net

  # =========================================================================
  # 4. RabbitMQ 队列 - 升级为最新的 4.0-management 版本
  # =========================================================================
  rabbitmq:
    image: rabbitmq:management
    container_name: micro-rabbitmq
    restart: always
    mem_limit: 350m
    environment:
      RABBITMQ_DEFAULT_USER: root
      RABBITMQ_DEFAULT_PASS: "111111"
    ports:
      - "5672:5672"
      - "15672:15672"
    volumes:
      - ./data/rabbitmq:/var/lib/rabbitmq
    networks:
      - micro-net

  # =========================================================================
  # 5. MinIO 对象存储 - 保持最新的 latest 镜像
  # =========================================================================
  minio:
    image: minio/minio:latest
    container_name: micro-minio
    restart: always
    mem_limit: 256m
    environment:
      MINIO_ROOT_USER: root
      MINIO_ROOT_PASSWORD: admin111111
      GOMAXPROCS: 2
      TZ: Asia/Shanghai
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - ./data/minio/data:/data
      - ./data/minio/config:/root/.minio
    command: server /data --console-address ":9001"
    networks:
      - micro-net

networks:
  micro-net:
    driver: bridge
```

## 4. 各中间件详细说明

### 4.1 MySQL 8.4

| 项目 | 详情 |
|------|------|
| 镜像版本 | `mysql:8.4` |
| 容器名称 | `mysql` |
| 端口映射 | `3306:3306` |
| Root 密码 | `111111` |
| 字符集 | `utf8mb4`，排序规则 `utf8mb4_unicode_ci` |
| 时区 | `Asia/Shanghai`（UTC+8） |
| 数据持久化 | `./mysql/data:/var/lib/mysql`（重启数据不丢失） |
| 重启策略 | `always`（容器异常退出自动重启） |

**自定义配置文件** (`./mysql/conf/my.cnf`)：
```ini
[mysqld]
# 最大连接数
max_connections = 200
# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
# InnoDB 缓冲池（建议设为内存 25-50%，当前环境约 256MB）
innodb_buffer_pool_size = 256M
```

**首次启动后初始化**：
```sql
-- 连接 MySQL
docker exec -it mysql mysql -u root -p111111

-- 创建业务数据库
CREATE DATABASE user_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE file_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 4.2 Redis 8.0

| 项目 | 详情 |
|------|------|
| 镜像版本 | `redis:8.0` |
| 容器名称 | `redis` |
| 端口映射 | `6379:6379` |
| 认证密码 | `111111` |
| 最大内存 | `96mb` |
| 内存淘汰策略 | `allkeys-lru`（内存满时淘汰最久未使用的 Key） |
| 持久化 | AOF 开启（防止重启后 Token 全部失效） |
| 数据持久化 | `./redis/data:/data` |

**Redis 配置文件** (`./redis/conf/redis.conf`)：
```conf
# 绑定所有网络接口（Docker 内部）
bind 0.0.0.0

# 设置访问密码
requirepass 111111

# 最大内存限制
maxmemory 96mb

# 内存淘汰策略（LRU）
maxmemory-policy allkeys-lru

# 开启 AOF 持久化
appendonly yes
appendfsync everysec

# 禁用保护模式（Docker 网络内部通信安全）
protected-mode no
```

### 4.3 Nacos 3.2.2

| 项目 | 详情 |
|------|------|
| 镜像版本 | `nacos/nacos-server:v3.2.2` |
| 容器名称 | `nacos` |
| 运行模式 | 单机模式（`standalone`） |
| HTTP API 端口 | `8848`（服务注册/配置 API） |
| Web 控制台端口 | `8847`（浏览器访问） |
| gRPC 端口 | `9848`（Spring Cloud Alibaba 客户端使用） |
| JVM 堆内存 | Xms=256m，Xmx=256m |
| 控制台地址 | `http://122.51.234.113:8847/` |
| 默认账号 | `nacos` / `nacos` |

**注意事项**：
- Nacos 3.x 版本将 UI 控制台端口分离为独立端口 `8847`，与 API 端口 `8848` 分开
- Spring Cloud Alibaba 客户端需配置 `server-addr: 122.51.234.113:8848`（API 端口）
- gRPC 端口（9848）= HTTP 端口（8848）+ 1000，Nacos 客户端自动使用

## 5. 启动与管理命令

```bash
# 启动所有中间件（后台运行）
docker compose up -d

# 查看运行状态
docker compose ps

# 查看某个容器日志
docker compose logs -f mysql
docker compose logs -f nacos

# 停止所有容器（不删除数据）
docker compose stop

# 重启某个容器
docker compose restart redis

# 停止并删除容器（数据保留在 Volume）
docker compose down
```

## 6. 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Nacos 启动失败 | 内存不足 | 降低 JVM 配置：Xms=128m, Xmx=128m |
| Redis 连接被拒绝 | 密码配置错误 | 检查 requirepass 与应用配置是否一致 |
| MySQL 中文乱码 | 字符集配置问题 | 确认建库时指定 utf8mb4 |
| MinIO 控制台无法访问 | 端口未开放 | 检查防火墙/安全组规则 |
