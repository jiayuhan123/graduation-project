## 1. 概述

本项目所有中间件通过 **Docker Compose** 统一编排部署，一键启动。部署目录结构如下：

```
~/graduation-project/middleware/
├── docker-compose.yaml      # Docker Compose 编排文件
├── postgres/
│   ├── conf/               # PostgreSQL 自定义配置
│   └── data/               # PostgreSQL 数据持久化（Volume）
├── redis/
│   └── conf/               # Redis 配置文件
├── nacos/
│   └── logs/               # Nacos 日志
├── rabbitmq/
│   └── data/               # RabbitMQ 数据持久化
└── minio/
    └── data/               # MinIO 文件持久化
```

## 3. Docker Compose 配置文件

```yaml
version: '3.8'

services:
  # =========================================================================
  # 1. PostgreSQL (业务数据库) - 18 最新版
  # =========================================================================
  postgres:
    image: postgres:18
    container_name: micro-postgres
    restart: always
    mem_limit: 512m
    environment:
      POSTGRES_USER: root
      POSTGRES_PASSWORD: "111111"
      TZ: Asia/Shanghai
    ports:
      - "5432:5432"
    volumes:
      - ./data/postgres/db:/var/lib/postgresql/data
    command: |
      -c shared_buffers=128MB
      -c max_connections=100
    networks:
      - micro-net

  # =========================================================================
  # 2. Redis 缓存 - 升级为最新的 8.0 极速版
  # =========================================================================
  redis:
    image: redis:8.0
    container_name: micro-redis
    restart: always
    mem_limit: 128m
    command: >
      redis-server 
      --requirepass 111111 
      --appendonly yes 
      --maxmemory 96mb 
      --maxmemory-policy allkeys-lru
    ports:
      - "6379:6379"
    volumes:
      - ./data/redis:/data
    networks:
      - micro-net

  # =========================================================================
  # 3. Nacos 注册 & 配置中心 - 升级为最新的 3.2.2 版本
  # =========================================================================
  nacos:
    image: nacos/nacos-server:v3.2.2
    container_name: micro-nacos
    restart: always
    mem_limit: 512m
    environment:
      MODE: standalone
      JVM_XMS: 256m
      JVM_XMX: 256m
      JVM_XMN: 128m
      NACOS_AUTH_IDENTITY_KEY: nacos_identity_project
      NACOS_AUTH_IDENTITY_VALUE: nacos_identity_value_111111
      NACOS_AUTH_TOKEN: SecretKey012345678901234567890123456789012345678901234567890123456789
      TZ: Asia/Shanghai
    ports:
      - "8848:8848"  # API 端口
      - "8847:8080"  # 3.x 独立控制台端口
      - "9848:9848"
      - "9849:9849"
    volumes:
      - ./data/nacos/logs:/home/nacos/logs
      - ./data/nacos/data:/home/nacos/data
    networks:
      - micro-net

  # =========================================================================
  # 4. RabbitMQ 队列 - 升级为最新的 4.0-management 版本
  # =========================================================================
  rabbitmq:
    image: rabbitmq:management
    container_name: micro-rabbitmq
    restart: always
    mem_limit: 350m
    environment:
      RABBITMQ_DEFAULT_USER: root
      RABBITMQ_DEFAULT_PASS: "111111"
    ports:
      - "5672:5672"
      - "15672:15672"
    volumes:
      - ./data/rabbitmq:/var/lib/rabbitmq
    networks:
      - micro-net

  # =========================================================================
  # 5. MinIO 对象存储 - 保持最新的 latest 镜像
  # =========================================================================
  minio:
    image: minio/minio:latest
    container_name: micro-minio
    restart: always
    mem_limit: 256m
    environment:
      MINIO_ROOT_USER: root
      MINIO_ROOT_PASSWORD: admin111111
      GOMAXPROCS: 2
      TZ: Asia/Shanghai
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - ./data/minio/data:/data
      - ./data/minio/config:/root/.minio
    command: server /data --console-address ":9001"
    networks:
      - micro-net

  # =========================================================================
  # 6. Jenkins - 自动化构建部署 (极致压缩版)
  # =========================================================================
  jenkins:
    image: jenkins/jenkins:lts
    container_name: micro-jenkins
    restart: always
    mem_limit: 800m
    user: root 
    environment:
      - JAVA_OPTS=-Xms128m -Xmx256m -XX:MaxMetaspaceSize=128m
      - TZ=Asia/Shanghai
    ports:
      - "8080:8080"
      - "50000:50000"
    volumes:
      - ./data/jenkins:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock
    networks:
      - micro-net

networks:
  micro-net:
    driver: bridge
```

## 4. 各中间件详细说明

### 4.1 PostgreSQL 18

| 项目 | 详情 |
|------|------|
| 镜像版本 | `postgres:18` |
| 容器名称 | `postgres` |
| 端口映射 | `5432:5432` |
| 超级用户 | `root` / `111111` |
| 字符集 | UTF-8（内置支持） |
| 时区 | `Asia/Shanghai`（UTC+8） |
| 数据持久化 | `./postgres/data:/var/lib/postgresql/data`（重启数据不丢失） |
| 重启策略 | `always`（容器异常退出自动重启） |

**自定义配置**（`./postgres/conf/postgresql.conf`，可通过 command 参数注入）：
```conf
# 共享缓冲区（建议设为内存 25% 左右，当前环境约 128MB）
shared_buffers = 128MB
# 最大连接数
max_connections = 100
# 慢查询日志
log_min_duration_statement = 2000
```

**首次启动后初始化**（创建各服务独立 Schema）：
```sql
-- 连接 PostgreSQL
psql -h 127.0.0.1 -U root -d postgres

-- 创建业务数据库（各微服务独占）
CREATE DATABASE user_db;
CREATE DATABASE memorial_db;
CREATE DATABASE file_db;
CREATE DATABASE notify_db;
```

> **说明**：各库建表 SQL 见《[文明祭扫系统数据库设计](../4-数据库设计/memorial_system_db_design.md)》。

### 4.2 Redis 8.0

| 项目 | 详情 |
|------|------|
| 镜像版本 | `redis:8.0` |
| 容器名称 | `redis` |
| 端口映射 | `6379:6379` |
| 认证密码 | `111111` |
| 最大内存 | `96mb` |
| 内存淘汰策略 | `allkeys-lru`（内存满时淘汰最久未使用的 Key） |
| 持久化 | AOF 开启（防止重启后 Token 全部失效） |
| 数据持久化 | `./redis/data:/data` |

**Redis 配置文件** (`./redis/conf/redis.conf`)：
```conf
# 绑定所有网络接口（Docker 内部）
bind 0.0.0.0

# 设置访问密码
requirepass 111111

# 最大内存限制
maxmemory 96mb

# 内存淘汰策略（LRU）
maxmemory-policy allkeys-lru

# 开启 AOF 持久化
appendonly yes
appendfsync everysec

# 禁用保护模式（Docker 网络内部通信安全）
protected-mode no
```

### 4.3 Nacos 3.2.2

| 项目 | 详情 |
|------|------|
| 镜像版本 | `nacos/nacos-server:v3.2.2` |
| 容器名称 | `nacos` |
| 运行模式 | 单机模式（`standalone`） |
| HTTP API 端口 | `8848`（服务注册/配置 API） |
| Web 控制台端口 | `8847`（浏览器访问） |
| gRPC 端口 | `9848`（Spring Cloud Alibaba 客户端使用） |
| JVM 堆内存 | Xms=256m，Xmx=256m |
| 控制台地址 | `http://122.51.234.113:8847/` |
| 默认账号 | `nacos` / `nacos` |

**注意事项**：
- Nacos 3.x 版本将 UI 控制台端口分离为独立端口 `8847`，与 API 端口 `8848` 分开
- Spring Cloud Alibaba 客户端需配置 `server-addr: 122.51.234.113:8848`（API 端口）
- gRPC 端口（9848）= HTTP 端口（8848）+ 1000，Nacos 客户端自动使用

### 4.6 Jenkins (LTS)

| 项目 | 详情 |
|------|------|
| 镜像版本 | `jenkins/jenkins:lts`（内置 Java 21 环境） |
| 容器名称 | `micro-jenkins` |
| Web 控制台端口 | `8080`（浏览器管理界面） |
| 通信端口 | `50000`（内部节点通讯，无需对公网开放） |
| 管理员账号 | `root` / `111111`（初始化安装插件后自行创建配置） |
| 控制台地址 | `http://122.51.234.113:8080` |
| 内存限制 | 容器封顶 800m，JVM 配置为 `Xms128m Xmx256m` |
| 数据持久化 | `./jenkins:/var/jenkins_home` |

**获取初始密码与配置**：
1. 启动后，在宿主机执行 `docker exec -it micro-jenkins cat /var/jenkins_home/secrets/initialAdminPassword` 获取密码。
2. 登录控制台后选择“安装推荐插件”。
3. **关键避坑**：为了防止打包时 OOM 闪退，必须在 Jenkins 系统设置里为 Maven 注入全局环境变量：`MAVEN_OPTS="-Xms128m -Xmx256m"`。

## 5. 启动与管理命令

```bash
# 启动所有中间件（后台运行）
docker compose up -d

# 查看运行状态
docker compose ps

# 查看某个容器日志
docker compose logs -f postgres
docker compose logs -f nacos

# 停止所有容器（不删除数据）
docker compose stop

# 重启某个容器
docker compose restart redis

# 停止并删除容器（数据保留在 Volume）
docker compose down
```

## 6. 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| Nacos 启动失败 | 内存不足 | 降低 JVM 配置：Xms=128m, Xmx=128m |
| Redis 连接被拒绝 | 密码配置错误 | 检查 requirepass 与应用配置是否一致 |
| PostgreSQL 连接失败 | 账号/密码或端口配置错误 | 检查 POSTGRES_USER/PASSWORD 与应用配置是否一致 |
| MinIO 控制台无法访问 | 端口未开放 | 检查防火墙/安全组规则 |
