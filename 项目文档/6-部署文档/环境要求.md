# 环境要求

## 开发工具

| 软件 | 要求 |
| --- | --- |
| JDK | 21 |
| Maven | 使用 `back/mvnw.cmd` / `mvnw` |
| Docker / Compose | Docker 24+、Compose V2 |
| Git | 2.x |

## 基础设施与云资源

| 组件 | 版本/方式 | 本地端口 |
| --- | --- | --- |
| PostgreSQL | `postgres:18` | 5432 |
| Redis | `redis:8.0` | 6379 |
| Nacos | `nacos/nacos-server:v3.2.2` | 8848、8847、9848、9849 |
| RabbitMQ | `rabbitmq:4.3.4-management` | 5672、15672 |
| Jenkins | `jenkins/jenkins:lts` | 8080、50000 |
| 阿里云 OSS | 托管云服务，私有 Bucket | HTTPS 443 |

项目不部署本地对象存储服务。文件服务必须能访问阿里云 OSS Endpoint，并具备目标私有 Bucket 的必要对象读写/删除权限。

## 网络边界

公网只应开放 HTTPS 反向代理/Gateway。8001—8004、数据库、Redis、RabbitMQ、Nacos 和管理控制台放在内网。生产环境不得使用仓库中的本地密码。

完整构建建议至少 2 GB 可用内存：

```powershell
cd back
.\mvnw.cmd clean verify
```
