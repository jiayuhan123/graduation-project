## 2. 必要软件版本

### 2.1 基础环境

| 软件 | 版本要求 | 安装说明 |
|------|----------|----------|
| **JDK** | 21（LTS） | 建议使用 OpenJDK 21 或 Eclipse Temurin 21 |
| **Maven** | 3.9+ | 构建 Spring Boot 项目 |
| **Docker** | 24.0+ | 容器运行时 |
| **Docker Compose** | 2.x+ | 容器编排（使用 V2 语法） |
| **Git** | 2.x+ | 代码版本管理 |

### 2.2 软件版本验证命令

```bash
# 验证 JDK 版本
java -version
# 期望输出：openjdk version "21.x.x" ...

# 验证 Maven 版本
mvn -version
# 期望输出：Apache Maven 3.9.x ...

# 验证 Docker 版本
docker --version
# 期望输出：Docker version 24.x.x ...

# 验证 Docker Compose 版本
docker compose version
# 期望输出：Docker Compose version v2.x.x

# 验证 Git 版本
git --version
```

### 2.3 JDK 安装（Linux）

```bash
# Ubuntu/Debian 安装 OpenJDK 21
sudo apt update
sudo apt install -y openjdk-21-jdk

# 验证
java -version

# 设置 JAVA_HOME（如有需要）
echo 'export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64' >> ~/.bashrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

## 3. 端口开放清单

### 3.1 必须对外开放的端口（防火墙/安全组规则）

| 端口 | 协议 | 服务 | 说明 |
|------|------|------|------|
| **10000** | TCP | API Gateway | 所有 API 请求的统一入口，**必须开放** |
| **22** | TCP | SSH | 远程登录服务器（建议限制来源IP） |

### 3.2 内部访问端口（仅 Docker 内网访问，不对外开放）

| 端口 | 协议 | 服务 | 说明 |
|------|------|------|------|
| 8001 | TCP | user-service | 用户服务（网关路由访问） |
| 3306 | TCP | MySQL | 数据库（仅 Docker 内网） |
| 6379 | TCP | Redis | 缓存（仅 Docker 内网） |
| 5672 | TCP | RabbitMQ | AMQP 消息端口（仅 Docker 内网） |
| 9000 | TCP | MinIO | S3 API 端口（仅 Docker 内网） |
| 9848 | TCP | Nacos | gRPC 注册端口（仅 Docker 内网） |

### 3.3 管理控制台端口（可按需对外开放，建议限制 IP）

| 端口 | 协议 | 服务 | 控制台 URL | 默认账号 |
|------|------|------|------------|----------|
| **8847** | TCP | Nacos 控制台 | `http://122.51.234.113:8847/nacos` | nacos/nacos |
| **15672** | TCP | RabbitMQ 管理台 | `http://122.51.234.113:15672` | root/111111 |
| **9001** | TCP | MinIO 控制台 | `http://122.51.234.113:9001` | root/admin111111 |

> ⚠️ **安全警告**：管理控制台端口包含敏感操作权限，生产环境应限制为特定 IP 访问，或通过 VPN/SSH 隧道访问，避免公网直接暴露。

### 3.4 阿里云安全组配置示例

```
# 入站规则
协议: TCP  端口: 10000  来源: 0.0.0.0/0      说明: API网关
协议: TCP  端口: 22     来源: {您的IP}/32     说明: SSH管理
协议: TCP  端口: 8847   来源: {您的IP}/32     说明: Nacos控制台
协议: TCP  端口: 15672  来源: {您的IP}/32     说明: RabbitMQ管理台
协议: TCP  端口: 9001   来源: {您的IP}/32     说明: MinIO控制台
```
