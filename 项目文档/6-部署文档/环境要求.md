# 环境要求

## 1. 开发环境

| 软件 | 版本/要求 | 说明 |
|---|---|---|
| JDK | 21 | 项目编译与运行版本 |
| Maven | Wrapper 自带 3.9.x | 优先使用 `back/mvnw` 或 `mvnw.cmd` |
| Docker Engine / Desktop | 24+ | 运行本地中间件 |
| Docker Compose | V2 插件 | 命令为 `docker compose` |
| Git | 2.x | 版本管理 |

验证命令：

```powershell
java -version
./back/mvnw.cmd -version
docker version
docker compose version
git --version
```

## 2. 当前基础组件

| 组件 | 仓库镜像/版本 | 本地端口 | 建议最低内存 |
|---|---|---:|---:|
| PostgreSQL | `postgres:18` | 5432 | 256 MB |
| Redis | `redis:8.0` | 6379 | 128 MB |
| Nacos | `nacos/nacos-server:v3.2.2` | 8848、8847、9848、9849 | 512 MB |
| RabbitMQ | `rabbitmq:management` | 5672、15672 | 350 MB |
| Jenkins | `jenkins/jenkins:lts` | 8080、50000 | 800 MB |
| Gateway | Spring Boot 4.0.6 | 10000 | 256 MB |
| User Service | Spring Boot 4.0.6 | 8001 | 384 MB |

当前用户服务运行只依赖 PostgreSQL、Redis 和 Nacos；RabbitMQ 与 Jenkins 是后续业务和 CI 基础设施。当前 Compose 没有 MinIO，选题确定并确需对象存储时再增加。

## 3. 网络与端口

生产环境对公网原则上只开放：

| 端口 | 用途 |
|---:|---|
| 10000 | API Gateway |
| 22 | SSH，且应限制来源 |
| 80/443 | 如果使用反向代理和 HTTPS |

`8001`、`5432`、`6379`、`5672`、`8848`、`9848` 等服务端口应位于内网。Nacos、RabbitMQ、Jenkins 控制台应通过 VPN、堡垒机或受限 IP 访问，不应使用仓库默认密码暴露到公网。

## 4. 配置要求

- 本地默认主机为 `localhost`；
- Docker 容器化部署时，服务地址改为 Compose 服务名，如 `postgres`、`redis`、`nacos`；
- 生产环境使用环境变量或 Nacos 注入密码和地址；
- Gateway 与 User Service 的 Sa-Token 配置、Redis 实例和数据库编号必须一致；
- PostgreSQL 只需创建空的 `user_db`，Flyway 自动迁移；
- 初始管理员通过临时环境变量创建，不在 SQL 或仓库中放默认密码。

## 5. 构建资源

完整 Maven 构建建议至少提供 2 GB 可用内存。低配服务器可设置：

```powershell
$env:MAVEN_OPTS="-Xms128m -Xmx768m"
./back/mvnw.cmd clean verify
```

应用 JVM 内存应结合压测调整，不直接照搬开发值到生产。
