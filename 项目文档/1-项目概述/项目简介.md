## 1. 项目背景

随着互联网应用规模的持续扩大，传统的单体架构（Monolithic Architecture）在面对高并发、高可用、快速迭代等需求时逐渐暴露出明显的局限性：服务间耦合度高、部署周期长、技术栈难以演进。微服务架构（Microservices Architecture）通过将应用拆分为一组小型、独立部署的服务，有效解决了上述问题，成为当前企业级应用架构的主流选择。

本项目以**微服务架构设计与实践**为核心命题，基于 Spring Cloud 生态构建一套完整的微服务后端系统，覆盖服务注册与发现、统一鉴权、配置中心、消息异步解耦、对象存储等企业级微服务核心能力，作为毕业设计的工程实践载体。

---

## 2. 项目目标

### 2.1 核心目标

1. **构建微服务基础架构**：实现基于 Spring Cloud 的完整微服务基础设施，包括注册中心、配置中心、API 网关等核心组件。
2. **实现统一鉴权体系**：基于 Sa-Token + Redis 在网关层实现统一鉴权，下游服务通过请求头安全获取用户身份。
3. **实践异步解耦通信**：通过 RabbitMQ 实现服务间异步消息通信，提升系统吞吐量与容错能力。
4. **实现容器化部署**：使用 Docker Compose 实现中间件的容器化编排，降低部署复杂度。
5. **输出完整文档体系**：建立符合工程规范的项目文档，涵盖架构设计、接口规范、部署指南等。

### 2.2 学术目标

- 深入理解微服务架构的设计原则与权衡取舍（Trade-off）
- 掌握 Spring Cloud Alibaba 生态的核心组件使用
- 实践 DevOps 理念中的容器化部署流程
- 具备完整的系统设计与文档撰写能力
