## 1. 项目结构规范

### 1.1 父工程结构

```
graduation-project/                    # 父工程（Maven Aggregator）
├── pom.xml                            # 父 POM，统一依赖版本管理
├── common/                            # 公共模块（工具类、统一响应、异常等）
│   └── src/main/java/xyz/jiayuhan/common/
│       ├── result/                    # 统一响应封装（Result、ResultCode）
│       ├── exception/                 # 自定义异常类
│       └── utils/                    # 工具类
├── gateway/                           # 网关服务
└── user-service/                      # 用户服务
```

### 1.2 单个微服务内部包结构

以 `user-service` 为例，基础包名为 `xyz.jiayuhan.user`：

```
xyz.jiayuhan.user/
├── UserServiceApplication.java        # 启动类
├── config/                            # 配置类（Bean 定义、框架配置）
│   ├── MybatisPlusConfig.java         # MyBatis-Plus 配置（分页插件等）
│   ├── RedisConfig.java               # Redis 配置
│   └── RabbitMQConfig.java            # RabbitMQ Exchange/Queue 定义
├── controller/                        # 控制器层（接收请求，参数校验，返回 Result）
│   └── UserController.java
├── service/                           # 服务层（业务逻辑，事务管理）
│   ├── UserService.java               # 接口
│   └── impl/
│       └── UserServiceImpl.java       # 实现类
├── mapper/                            # 数据访问层（MyBatis-Plus Mapper）
│   └── UserMapper.java
├── entity/                            # 数据库实体类（与表一一对应）
│   └── User.java
├── dto/                               # 数据传输对象（接收前端请求参数）
│   ├── UserRegisterDTO.java
│   ├── UserLoginDTO.java
│   └── UserUpdateDTO.java
├── vo/                                # 视图对象（返回给前端的数据）
│   ├── UserVO.java
│   └── LoginVO.java
├── handler/                           # 全局异常处理器
│   └── GlobalExceptionHandler.java
└── interceptor/                       # 拦截器（如 UserContext 注入）
    └── UserContextInterceptor.java
```

### 1.3 各层职责说明

| 层次 | 包名 | 职责 | 命名规范 |
|------|------|------|----------|
| 控制器层 | `controller` | 接收 HTTP 请求，参数校验（@Valid），调用 Service，返回 Result | `XxxController` |
| 服务接口层 | `service` | 定义业务接口，描述业务能力 | `XxxService` |
| 服务实现层 | `service/impl` | 实现业务逻辑，管理事务（@Transactional） | `XxxServiceImpl` |
| 数据访问层 | `mapper` | 继承 BaseMapper，定义复杂 SQL | `XxxMapper` |
| 实体层 | `entity` | 与数据库表对应的 Java 对象 | `Xxx`（如 User） |
| DTO 层 | `dto` | 前端请求参数封装，含 JSR-303 校验注解 | `XxxDTO` |
| VO 层 | `vo` | 接口响应数据封装，控制暴露字段 | `XxxVO` |
| 配置层 | `config` | Spring Bean 定义，框架配置类 | `XxxConfig` |

## 2. 命名规范

### 2.1 类命名（PascalCase）

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 普通类 | 名词，PascalCase | `UserService`、`OrderManager` |
| 接口 | 名词，PascalCase（无 I 前缀） | `UserService`、`FileRepository` |
| 实现类 | 接口名 + `Impl` | `UserServiceImpl` |
| 枚举类 | 名词，PascalCase | `ResultCode`、`UserStatus` |
| 异常类 | 名词 + `Exception` | `BusinessException`、`AuthException` |
| 常量类 | 名词 + `Constants` | `RedisConstants`、`MQConstants` |
| 工具类 | 名词 + `Utils` 或 `Util` | `StringUtils`、`DateUtil` |

### 2.2 方法命名（camelCase）

| 操作类型 | 推荐前缀 | 示例 |
|----------|----------|------|
| 查询（返回单个） | `get` / `find` | `getUserById()`、`findByUsername()` |
| 查询（返回列表） | `list` / `query` | `listUsers()`、`queryByCondition()` |
| 查询（返回分页） | `page` | `pageUsers()` |
| 查询（返回布尔） | `is` / `has` / `exists` | `isUsernameExists()`、`hasPermission()` |
| 新增 | `save` / `create` / `add` | `saveUser()`、`createOrder()` |
| 修改 | `update` / `modify` | `updateUserInfo()`、`modifyPassword()` |
| 删除 | `remove` / `delete` | `removeById()`、`deleteByUserId()` |
| 发送 | `send` | `sendMessage()`、`sendEmail()` |

### 2.3 变量命名（camelCase）

```java
// ✅ 正确示例
String username;
Long userId;
List<UserVO> userList;
Map<Long, String> userIdNameMap;
boolean isValid;

// ❌ 错误示例
String UserName;         // 首字母不应大写
String user_name;        // 不使用下划线
String strUsername;      // 不使用匈牙利命名法
```

### 2.4 常量命名（全大写 + 下划线）

```java
// ✅ 正确示例
public static final String REDIS_TOKEN_PREFIX = "sa_token:";
public static final int MAX_RETRY_COUNT = 3;
public static final long TOKEN_EXPIRE_SECONDS = 604800L;
```

### 2.5 数据库字段命名（全小写 + 下划线）

```sql
-- ✅ 正确示例
user_id, create_time, is_deleted, mobile_phone

-- ❌ 错误示例
userId, CreateTime, isDeleted
```

## 3. 注释规范

### 3.1 类注释（Javadoc）

所有 `public` 类必须有 Javadoc 注释：

```java
/**
 * 用户服务实现类
 * <p>
 * 负责处理用户注册、登录、信息查询等业务逻辑。
 * </p>
 *
 * @author jiayuhan
 * @since 1.0.0
 */
@Service
public class UserServiceImpl implements UserService {
    // ...
}
```

### 3.2 方法注释

```java
/**
 * 根据用户ID查询用户信息
 *
 * @param userId 用户ID，不能为null
 * @return 用户信息 VO，若用户不存在则抛出 BusinessException
 * @throws BusinessException 用户不存在时抛出，错误码 404
 */
UserVO getUserById(Long userId);
```

### 3.3 行内注释

```java
// ✅ 好的行内注释（解释"为什么"）
// BCrypt 加密是单向的，无法解密，只能重新生成比对
String encodedPassword = passwordEncoder.encode(dto.getPassword());

// ❌ 不好的行内注释（仅描述"是什么"，代码本身已经说明）
// 调用 encode 方法
String encodedPassword = passwordEncoder.encode(dto.getPassword());
```

## 4. Lombok 使用规范

### 4.1 常用注解

```java
@Data           // 相当于 @Getter + @Setter + @ToString + @EqualsAndHashCode + @RequiredArgsConstructor
@Builder        // 建造者模式（需配合 @AllArgsConstructor + @NoArgsConstructor 使用）
@NoArgsConstructor    // 无参构造器
@AllArgsConstructor   // 全参构造器
@Slf4j          // 自动注入 log 变量（替代手写 Logger）
```

### 4.2 使用建议

```java
// ✅ 推荐：DTO/VO 等数据类使用 @Data
@Data
public class UserVO {
    private Long id;
    private String username;
}

// ✅ 推荐：使用 @Slf4j 记录日志
@Slf4j
@Service
public class UserServiceImpl implements UserService {
    
    public void someMethod() {
        log.info("开始处理用户：{}", userId);
        log.warn("用户 {} 状态异常", userId);
        log.error("用户 {} 注册失败", userId, e);  // 第三个参数传异常
    }
}

// ⚠️ 注意：@Data 在 Entity 类使用时，@EqualsAndHashCode 可能引发 JPA 问题
// 对于 MyBatis-Plus Entity，@Data 是安全的
```

## 5. Controller 层规范

```java
@Slf4j
@RestController
@RequestMapping("/api/user")
@RequiredArgsConstructor
public class UserController {

    private final UserService userService;

    /**
     * 用户注册
     */
    @PostMapping("/register")
    public Result<Map<String, Object>> register(@Valid @RequestBody UserRegisterDTO dto) {
        // Controller 只做：参数接收 + 调用 Service + 返回 Result
        // 不写任何业务逻辑！
        return userService.register(dto);
    }
    
    /**
     * 获取当前用户信息
     * X-User-ID 由网关注入，Controller 直接接收
     */
    @GetMapping("/info")
    public Result<UserVO> getUserInfo(@RequestHeader("X-User-ID") Long userId) {
        return Result.success(userService.getUserById(userId));
    }
}
```

## 6. Service 层规范

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    private final UserMapper userMapper;
    private final PasswordEncoder passwordEncoder;

    @Override
    @Transactional(rollbackFor = Exception.class)   // 写操作必须加事务
    public Result<Map<String, Object>> register(UserRegisterDTO dto) {
        // 1. 业务校验（不能放在 Controller）
        if (userMapper.existsByUsername(dto.getUsername())) {
            throw new BusinessException(ResultCode.USERNAME_EXISTS);
        }
        
        // 2. 构建实体
        User user = new User();
        user.setUsername(dto.getUsername());
        user.setPassword(passwordEncoder.encode(dto.getPassword()));
        
        // 3. 持久化
        userMapper.insert(user);
        
        log.info("用户注册成功，userId={}, username={}", user.getId(), user.getUsername());
        return Result.success(Map.of("id", user.getId(), "username", user.getUsername()));
    }
}
```
