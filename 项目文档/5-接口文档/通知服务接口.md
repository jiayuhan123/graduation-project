# 通知服务接口

基础路径 `/api/notifications`，全部要求登录，且只操作当前用户通知。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `?page=1&size=10&read=false` | 分页；`read` 可省略 |
| GET | `/unread-count` | 返回未读数量 |
| PUT | `/{notificationId}/read` | 幂等标记一条已读 |
| PUT | `/read-all` | 幂等标记全部已读 |

分页数据统一为：

```json
{
  "current": 1,
  "size": 10,
  "total": 1,
  "pages": 1,
  "records": [
    {
      "id": "c0a8012e-0000-4000-8000-000000000001",
      "type": "SYSTEM",
      "title": "欢迎使用",
      "content": "账号 demo 已注册成功，欢迎使用本系统。",
      "read": false,
      "readAt": null,
      "createdAt": "2026-08-19T12:00:00"
    }
  ]
}
```

页码从 1 开始，`size` 范围 1—100。通知不存在或不属于当前用户返回业务码 `3000`。
