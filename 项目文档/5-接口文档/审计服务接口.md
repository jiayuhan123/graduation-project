# 审计服务接口

当前只开放个人审计查询：

`GET /api/audits/me?page=1&size=10&action=USER_REGISTERED`

| 参数 | 必填 | 约束 |
| --- | --- | --- |
| `page` | 否 | 默认 1，最小 1 |
| `size` | 否 | 默认 10，范围 1—100 |
| `action` | 否 | 精确匹配操作类型 |

记录字段包括 `id`、`source`、`action`、`targetType`、`targetId`、`detail` 和 `occurredAt`，分页结构使用公共 `PageResult`。

常见动作包括 `USER_REGISTERED` 及用户服务管理/RBAC 操作。审计详情不得包含密码、Token、AccessKey 等秘密。全局审计查询尚未开放；未来必须配置独立管理员权限和脱敏规则。
