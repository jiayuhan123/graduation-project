# 用户服务接口

## 1. 服务信息

| 项目 | 内容 |
|---|---|
| 服务名 | `user-service` |
| 默认端口 | `8001` |
| 网关前缀 | `/api/user` |
| 当前职责 | 用户注册、登录和 Token 签发 |

## 2. 用户注册

- 方法：`POST`
- 地址：`/api/user/register`
- 鉴权：否

请求示例：

```json
{
  "username": "user001",
  "password": "Test1234",
  "realName": "测试用户",
  "phone": "13800138000"
}
```

成功响应示例：

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "userId": 1,
    "username": "user001"
  }
}
```

## 3. 用户登录

- 方法：`POST`
- 地址：`/api/user/login`
- 鉴权：否
- 账号字段支持用户名或手机号。

请求示例：

```json
{
  "username": "user001",
  "password": "Test1234"
}
```

成功响应中的 `data` 包含 Token、用户标识、默认角色 `user` 和过期时间。客户端应使用响应给出的 `tokenName` 作为请求头名称。

## 4. 当前错误码

| 错误码 | 含义 |
|---:|---|
| 1001 | 用户名或密码错误 |
| 1002 | 用户名已存在 |
| 1003 | 手机号已被注册 |
| 1004 | 账号已被禁用 |
| 1005 | 旧密码不正确 |

其余个人信息、角色权限和新业务接口待新选题确认后设计。
