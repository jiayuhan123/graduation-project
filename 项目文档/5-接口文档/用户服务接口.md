# 通用用户服务接口

## 1. 服务约定

| 项目 | 内容 |
|---|---|
| 服务名 | `user-service` |
| 默认端口 | `8001` |
| 外部入口 | `http://localhost:10000/api/user/**` |
| Token 请求头 | 登录响应的 `tokenName`，默认 `satoken` |
| 响应结构 | `Result<T>`：`code`、`message`、`data` |
| ID 类型 | 后端为 `Long`，客户端应按字符串安全处理 |

公开接口只有注册和登录。其余接口都需要有效 Token；`/admin/**` 还会在用户服务内部检查权限码。

## 2. 认证接口

### 2.1 注册

`POST /api/user/register`

```json
{
  "username": "user001",
  "password": "Test1234",
  "nickname": "小明",
  "realName": "测试用户",
  "email": "user001@example.com",
  "phone": "13800138000"
}
```

规则：

- `username` 必填，3—32 位，以字母开头，只包含字母、数字和下划线；入库时转小写；
- `password` 必填，6—72 位，使用 BCrypt 保存；
- `nickname`、`realName`、`email`、`phone` 均可选；
- 邮箱入库时转小写；用户名、邮箱、手机号在未删除账号中唯一；
- 注册成功自动分配 `user` 角色。

成功响应：

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 1900000000000000001,
    "username": "user001"
  }
}
```

### 2.2 登录

`POST /api/user/login`

`username` 字段可以填写用户名、手机号或邮箱。

```json
{
  "username": "user001",
  "password": "Test1234"
}
```

成功响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "9e66e4d9-...",
    "tokenName": "satoken",
    "userId": 1900000000000000001,
    "username": "user001",
    "role": "user",
    "roles": ["user"],
    "permissions": [],
    "timeout": 604800,
    "expireAt": "2026-08-26T20:00:00"
  }
}
```

`role` 是兼容旧客户端的主角色；新代码应使用 `roles` 和 `permissions`。密码错误和账号不存在统一返回 `1001`。同一账号默认在 15 分钟内连续失败 5 次后返回 `1008`。

### 2.3 退出与会话

| 方法 | 路径 | 响应数据 |
|---|---|---|
| POST | `/api/user/logout` | 无 |
| GET | `/api/user/session` | 用户 ID、Token、角色、权限、剩余有效期 |

## 3. 个人账户接口

### 3.1 查询资料

`GET /api/user/me`

返回用户名、昵称、姓名、邮箱、手机号、头像、状态、角色、权限和时间字段，不返回密码哈希。

### 3.2 修改资料

`PUT /api/user/me`

```json
{
  "nickname": "新昵称",
  "realName": "测试用户",
  "email": "new@example.com",
  "phone": "13900139000",
  "avatarUrl": "https://example.com/avatar.png"
}
```

该接口不能修改用户名、状态、角色和密码。字段传 `null` 或空白字符串表示清空可选资料。

### 3.3 修改密码

`PUT /api/user/me/password`

```json
{
  "oldPassword": "Test1234",
  "newPassword": "NewTest1234"
}
```

修改成功后，该账号全部已有会话失效，客户端需要重新登录。

## 4. 管理端用户接口

### 4.1 分页查询

`GET /api/user/admin/users?page=1&size=10&keyword=user&status=1`

| 参数 | 必填 | 说明 |
|---|---|---|
| `page` | 否 | 默认 1 |
| `size` | 否 | 默认 10，最大 100 |
| `keyword` | 否 | 匹配用户名、昵称、姓名、邮箱或手机号 |
| `status` | 否 | 1 正常，0 禁用 |

响应 `data` 包含 `page`、`size`、`total`、`pages`、`records`。

### 4.2 用户维护

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin/users/{id}` | `system:user:query` | 用户详情 |
| POST | `/admin/users` | `system:user:create` | 创建用户，可指定状态和角色 |
| PUT | `/admin/users/{id}` | `system:user:update` | 修改资料 |
| PUT | `/admin/users/{id}/status` | `system:user:status` | 请求体 `{"status":0}` |
| PUT | `/admin/users/{id}/roles` | `system:user:role` | 请求体 `{"roleIds":[1]}` |
| PUT | `/admin/users/{id}/password` | `system:user:password-reset` | 请求体 `{"newPassword":"..."}` |
| DELETE | `/admin/users/{id}` | `system:user:delete` | 逻辑删除 |

表中路径均省略公共前缀 `/api/user`。禁用、删除、分配角色或重置密码后，目标账号已有会话失效。管理员不能用这些管理接口禁用、删除、重置自己或修改自己的角色。

## 5. 角色权限接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/user/admin/roles` | `system:role:list` | 角色及所含权限 |
| POST | `/api/user/admin/roles` | `system:role:create` | 创建自定义角色 |
| PUT | `/api/user/admin/roles/{id}` | `system:role:update` | 修改名称和描述 |
| PUT | `/api/user/admin/roles/{id}/status` | `system:role:update` | 启用/禁用 |
| PUT | `/api/user/admin/roles/{id}/permissions` | `system:role:permission` | 替换权限 ID 列表 |
| DELETE | `/api/user/admin/roles/{id}` | `system:role:delete` | 删除未使用角色 |
| GET | `/api/user/admin/permissions` | `system:permission:list` | 权限字典 |

创建角色示例：

```json
{
  "code": "operator",
  "name": "运营人员",
  "description": "拥有选题后新增的运营权限"
}
```

`admin` 和 `user` 是内置角色，不能禁用、删除或重新分配权限。权限字典由数据库迁移维护；新业务增加权限时，应新增迁移脚本并再分配给角色。

## 6. 错误码

| code | 含义 |
|---:|---|
| 400 | 参数校验失败 |
| 401 | 未登录或会话失效 |
| 403 | 无角色/权限 |
| 409 | 数据库唯一约束冲突 |
| 1001 | 用户名或密码错误 |
| 1002 | 用户名已存在 |
| 1003 | 手机号已被注册 |
| 1004 | 账号已禁用 |
| 1005 | 旧密码错误 |
| 1006 | 用户不存在 |
| 1007 | 邮箱已被注册 |
| 1008 | 登录失败次数过多 |
| 1009 | 角色不存在或不可用 |
| 1010 | 角色编码已存在 |
| 1011 | 内置角色受保护 |
| 1012 | 禁止对当前账号执行该管理操作 |
| 1013 | 角色正在使用 |
| 1014 | 权限不存在 |
| 1015 | 新旧密码相同 |

## 7. 在线文档

- Swagger UI：`http://localhost:8001/swagger-ui.html`；
