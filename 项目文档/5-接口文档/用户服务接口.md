## 3. 接口详情

### 3.1 US-API-001：居民注册

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/user/register` |
| 是否需要鉴权 | ❌ 否（白名单接口） |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 长度 | 说明 |
|--------|------|------|------|------|
| `username` | String | ✅ 是 | 3-20 | 用户名，只能包含字母/数字/下划线 |
| `password` | String | ✅ 是 | 6-20 | 登录密码（明文传输，服务端 BCrypt 加密） |
| `realName` | String | ❌ 否 | ≤50 | 真实姓名 |
| `phone` | String | ✅ 是 | 11位 | 手机号码（1开头11位数字） |

**请求示例**：
```json
{
    "username": "resident001",
    "password": "mypassword123",
    "realName": "张三",
    "phone": "13800138000"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "注册成功",
    "data": {
        "id": 1001,
        "username": "resident001"
    }
}
```

**失败响应示例**：
```json
{
    "code": 1002,
    "message": "用户名已存在",
    "data": null
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 请求参数校验失败（如用户名格式错误） |
| 1002 | 用户名已存在 |
| 1003 | 手机号已存在 |

> **说明**：注册成功后，用户服务发布 `user.register` 消息到 RabbitMQ，由通知服务发送欢迎站内信。

### 3.2 US-API-002：居民登录

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/user/login` |
| 是否需要鉴权 | ❌ 否（白名单接口） |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `username` | String | ✅ 是 | 用户名或手机号 |
| `password` | String | ✅ 是 | 登录密码（明文） |

**请求示例**：
```json
{
    "username": "resident001",
    "password": "mypassword123"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "登录成功",
    "data": {
        "token": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "tokenName": "satoken",
        "userId": 1001,
        "username": "resident001",
        "role": "resident",
        "expireAt": "2026-08-13T22:00:00"
    }
}
```

**失败响应示例**：
```json
{
    "code": 1001,
    "message": "用户名或密码错误",
    "data": null
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数为空（用户名或密码未传） |
| 1001 | 用户名或密码错误 |
| 1004 | 账号已被禁用 |

**前端使用说明**：登录成功后，客户端需保存 `data.token`，后续所有需要鉴权的请求在请求头中携带：
```http
satoken: a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

### 3.3 US-API-003：获取当前居民信息

| 项目 | 内容 |
|------|------|
| 接口地址 | `GET /api/user/info` |
| 是否需要鉴权 | ✅ 是 |
| 请求头 | `satoken: {token}` |

**请求参数**：无（身份通过 Token 识别）

**请求示例**：
```http
GET /api/user/info HTTP/1.1
Host: 122.51.234.113:10000
satoken: a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "id": 1001,
        "username": "resident001",
        "realName": "张三",
        "phone": "138****8000",
        "avatar": "http://122.51.234.113:9000/avatar/user-1001.jpg",
        "role": "resident",
        "community": {
            "id": 2001,
            "name": "幸福小区",
            "address": "XX市XX区幸福路1号"
        },
        "status": 1,
        "createTime": "2026-08-06T10:00:00"
    }
}
```

> **说明**：手机号进行脱敏处理后返回；`community` 为当前所属社区，未加入社区时为 `null`。

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 401 | Token 无效或已过期 |

### 3.4 US-API-004：修改居民信息

| 项目 | 内容 |
|------|------|
| 接口地址 | `PUT /api/user/info` |
| 是否需要鉴权 | ✅ 是 |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 长度 | 说明 |
|--------|------|------|------|------|
| `realName` | String | ❌ 否 | ≤50 | 真实姓名 |
| `phone` | String | ❌ 否 | 11位 | 新手机号 |
| `avatar` | String | ❌ 否 | ≤255 | 新头像 URL（file-service 上传后返回） |

> **说明**：所有字段均为可选，只更新传入的字段（Partial Update）。用户名不允许修改。

**请求示例**：
```json
{
    "realName": "张三丰",
    "avatar": "http://122.51.234.113:9000/avatar/user-1001-new.jpg"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "修改成功",
    "data": null
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数格式错误（如手机号格式不正确） |
| 401 | Token 无效或已过期 |
| 1003 | 新手机号已被其他居民使用 |

### 3.5 US-API-005：修改密码

| 项目 | 内容 |
|------|------|
| 接口地址 | `PUT /api/user/password` |
| 是否需要鉴权 | ✅ 是 |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `oldPassword` | String | ✅ 是 | 当前密码（明文） |
| `newPassword` | String | ✅ 是 | 新密码（明文，6-20 位） |
| `confirmPassword` | String | ✅ 是 | 确认新密码（与 newPassword 一致） |

**请求示例**：
```json
{
    "oldPassword": "mypassword123",
    "newPassword": "newpassword456",
    "confirmPassword": "newpassword456"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "密码修改成功，请重新登录",
    "data": null
}
```

> **说明**：密码修改成功后，服务端会使当前 Token 失效，客户端需要重新登录。

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 新密码与确认密码不一致；新密码长度不符合要求 |
| 401 | Token 无效或已过期 |
| 1005 | 旧密码不正确 |

### 3.6 US-API-006：退出登录

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/user/logout` |
| 是否需要鉴权 | ✅ 是 |

**请求参数**：无

**请求示例**：
```http
POST /api/user/logout HTTP/1.1
Host: 122.51.234.113:10000
satoken: a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "退出成功",
    "data": null
}
```

> **说明**：退出登录后，服务端立即删除 Redis 中的 Token，使该 Token 永久失效。

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 401 | Token 无效（Token 已过期，忽略此错误即可） |

**请求参数（Body）**：

```json
{

```

```json
{
```

## 4. 全局错误响应

以下错误由网关层返回（非用户服务）：

**401 未登录（网关返回）**：
```json
{
    "code": 401,
    "message": "请先登录",
    "data": null
}
```

**429 请求过于频繁（限流返回）**：
```json
{
    "code": 429,
    "message": "请求过于频繁，请稍后重试",
    "data": null
}
```

**500 服务器内部错误**：
```json
{
    "code": 500,
    "message": "服务器内部错误，请联系管理员",
    "data": null
}
```
