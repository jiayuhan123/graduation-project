## 3. 接口详情

### 3.1 MS-API-001：创建纪念档案

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/memorial/deceased` |
| 是否需要鉴权 | ✅ 是 |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 长度 | 说明 |
|--------|------|------|------|------|
| `name` | String | ✅ 是 | ≤50 | 逝者姓名 |
| `gender` | Integer | ❌ 否 | — | 性别：0未知，1男，2女 |
| `birthDate` | String | ❌ 否 | — | 出生日期（yyyy-MM-dd） |
| `deathDate` | String | ❌ 否 | — | 逝世日期（yyyy-MM-dd） |
| `avatar` | String | ❌ 否 | ≤255 | 遗照 URL（file-service 上传后返回） |
| `biography` | String | ❌ 否 | ≤2000 | 生平简介（服务端做敏感词过滤） |

**请求示例**：
```json
{
    "name": "李先人",
    "gender": 1,
    "birthDate": "1940-05-01",
    "deathDate": "2020-03-20",
    "avatar": "http://122.51.234.113:9000/deceased/photo-2001.jpg",
    "biography": "一生勤劳朴实，深受邻里敬重。"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "创建成功，等待社区管理员审核",
    "data": {
        "id": 3001,
        "status": 0
    }
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败 |
| 1103 | 不属于该社区成员（需先加入社区） |
| 1204 | 生平简介含敏感词 |

> **说明**：新档案状态为 `0待审核`，审核通过前仅创建者本人可见。

### 3.4 MS-API-004：档案审核

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/memorial/deceased/{id}/audit` |
| 是否需要鉴权 | ✅ 是 |
| 权限要求 | 社区管理员（`@SaCheckRole("community_admin")`） |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `pass` | Boolean | ✅ 是 | true=通过，false=驳回 |
| `reason` | String | ❌ 否 | 驳回原因（驳回时必填） |

**请求示例**：
```json
{
    "pass": true
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "审核完成",
    "data": null
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 1201 | 纪念档案不存在 |
| 1202 | 档案已审核（仅待审核状态可审核） |
| 1203 | 无权限操作该档案（非本社区管理员） |

> **说明**：审核完成后发布 `memorial.audit` 消息到 RabbitMQ，通知服务向创建者发送审核结果站内信。

### 3.5 MS-API-005：线上祭扫

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/memorial/records` |
| 是否需要鉴权 | ✅ 是 |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `deceasedId` | Long | ✅ 是 | 逝者档案 ID |
| `recordType` | String | ✅ 是 | `flower`献花 / `candle`点烛 / `incense`上香 / `message`留言 |
| `content` | String | ❌ 否 | 留言内容（recordType=message 时必填，≤200字） |

**请求示例**：
```json
{
    "deceasedId": 3001,
    "recordType": "message",
    "content": "愿老人家在天堂安好，晚辈永远怀念您。"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "祭扫成功",
    "data": {
        "id": 4001,
        "deceasedId": 3001,
        "recordType": "message",
        "createTime": "2026-08-06T10:30:00"
    }
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（类型不合法/留言为空） |
| 1201 | 纪念档案不存在 |
| 1202 | 档案未通过审核，不能祭扫 |
| 1204 | 留言内容含敏感词 |

### 3.7 MS-API-007：预约时段查询

| 项目 | 内容 |
|------|------|
| 接口地址 | `GET /api/memorial/appointments/slots` |
| 是否需要鉴权 | ✅ 是 |

**请求参数（Query）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `date` | String | ❌ | 指定日期（yyyy-MM-dd），默认查询未来 7 天 |

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "date": "2026-08-07",
        "slots": [
            {
                "timeSlot": "08:00-10:00",
                "capacity": 50,
                "booked": 23,
                "available": 27
            },
            {
                "timeSlot": "10:00-12:00",
                "capacity": 50,
                "booked": 50,
                "available": 0
            }
        ]
    }
}
```

> **说明**：`available=0` 的时段不可预约；时段名额与已预约数由 Redis 维护，支持高并发原子扣减。

### 3.8 MS-API-008：创建预约

| 项目 | 内容 |
|------|------|
| 接口地址 | `POST /api/memorial/appointments` |
| 是否需要鉴权 | ✅ 是 |
| Content-Type | `application/json` |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `appointmentDate` | String | ✅ 是 | 预约日期（yyyy-MM-dd） |
| `timeSlot` | String | ✅ 是 | 预约时段（如：08:00-10:00） |
| `deceasedId` | Long | ❌ | 关联纪念档案（可选） |
| `remark` | String | ❌ | 备注（如同行人数） |

**请求示例**：
```json
{
    "appointmentDate": "2026-08-08",
    "timeSlot": "08:00-10:00",
    "deceasedId": 3001,
    "remark": "一家三口前往祭扫"
}
```

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "预约提交成功，等待社区管理员确认",
    "data": {
        "id": 5001,
        "status": 0
    }
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（日期/时段不合法） |
| 1301 | 预约时段已满额 |
| 1302 | 该时段已存在预约 |

> **说明**：同一居民同一天同一时段仅可预约一次（数据库唯一约束兜底）；提交后状态为 `0待确认`。

### 3.11 MS-API-011：确认预约

| 项目 | 内容 |
|------|------|
| 接口地址 | `PUT /api/memorial/appointments/{id}/confirm` |
| 是否需要鉴权 | ✅ 是 |
| 权限要求 | 社区管理员（`@SaCheckRole("community_admin")`） |

**请求参数（Body）**：

| 参数名 | 类型 | 必须 | 说明 |
|--------|------|------|------|
| `confirm` | Boolean | ✅ 是 | true=确认，false=拒绝 |
| `reason` | String | ❌ 否 | 拒绝原因 |

**成功响应（200）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": null
}
```

**可能的错误码**：

| 错误码 | 说明 |
|--------|------|
| 1303 | 预约状态不允许该操作（仅待确认状态可处理） |
| 1203 | 无权限操作该预约（非本社区管理员） |

> **说明**：确认后发布 `memorial.appointment` 消息到 RabbitMQ，通知服务向居民发送预约确认/拒绝提醒；预约日期前 1 天自动发送临近祭扫提醒。

## 4. 全局错误响应

以下错误由网关层返回（非祭扫服务）：

**401 未登录（网关返回）**：
```json
{
    "code": 401,
    "message": "请先登录",
    "data": null
}
```

**403 无权限**：
```json
{
    "code": 403,
    "message": "无权限操作",
    "data": null
}
```

**500 服务器内部错误**：
```json
{
    "code": 500,
    "message": "服务器内部错误，请联系管理员",
    "data": null
}
```
