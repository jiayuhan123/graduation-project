# 文件服务接口

基础路径 `/api/files`，所有接口必须通过 Gateway 携带有效 `satoken`。文件 ID 为 UUID；服务只允许所有者访问，越权与不存在统一返回业务码 `2000`。

## 上传

`POST /api/files`，`Content-Type: multipart/form-data`，文件字段名 `file`。默认单文件最大 20 MB。

成功响应数据：

```json
{
  "id": "c0a8012e-0000-4000-8000-000000000001",
  "originalName": "report.pdf",
  "contentType": "application/pdf",
  "sizeBytes": 1024,
  "sha256": "64位十六进制摘要",
  "createdAt": "2026-08-19T12:00:00"
}
```

## 查询与下载

| 方法 | 路径 | 返回 |
| --- | --- | --- |
| GET | `/{fileId}/metadata` | 统一 JSON 元数据 |
| GET | `/{fileId}` | 附件二进制，带安全的 `Content-Disposition` |

下载由服务代理，不暴露 OSS 地址或 AccessKey。

## 删除

`DELETE /api/files/{fileId}`。先删除 OSS 对象，再逻辑删除元数据；OSS 失败时保留元数据供运维重试。

## 错误码

| 业务码 | 说明 |
| ---: | --- |
| 2000 | 文件不存在或不属于当前用户 |
| 2001 | 上传、对象存储写入或删除失败 |
| 2002 | 超过上传大小限制 |
| 400 / 401 | 参数错误 / 未登录 |
