## 当前后端模块

| 服务 | 端口 | 数据库/外部资源 |
| --- | ---: | --- |
| Gateway | 10000 | Nacos、Redis |
| User Service | 8001 | `user_db`、Redis、RabbitMQ |
| File Service | 8002 | `file_db`、阿里云 OSS |
| Notification Service | 8003 | `notification_db`、RabbitMQ |
| Audit Service | 8004 | `audit_db`、RabbitMQ |

选题确定后，领域数据不得继续堆入用户服务；应按清晰边界增加服务，并同步更新本文档索引。
