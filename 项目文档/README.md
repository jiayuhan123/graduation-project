## 当前基础模块

| 模块 | 默认端口 | 用途 |
|---|---:|---|
| Gateway | 10000 | 统一入口、路由、鉴权、跨域和接口文档聚合 |
| User Service | 8001 | 通用认证、账户、用户管理和 RBAC |
| Management | 5173（开发） | Vue 3 管理端基础页面 |
| Client App | 由运行平台决定 | UniApp 客户端基础页面 |
