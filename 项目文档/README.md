## 项目简介

本项目为毕业设计课题《**面向特定社区的文明祭扫系统设计与实现**》，基于 **Spring Cloud 微服务架构**，采用 JDK 21 + Spring Boot 4.0.6 + Spring Cloud 2025.1.1 + Spring Cloud Alibaba 2025.1.0.0 技术栈构建。系统面向特定社区（小区、街道等）提供线上线下结合的文明祭扫服务，涵盖**逝者纪念档案、线上祭扫、祭扫错峰预约、文明祭扫宣传**等核心业务，实现了服务注册发现、统一鉴权、配置中心、消息队列、对象存储等微服务核心能力。
