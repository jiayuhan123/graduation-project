## 2. 模块一：基础设施层

### 2.1 API 网关（gateway）

| 编号 | 功能名称 | 详细描述 | 优先级 | 状态 |
|------|----------|----------|--------|------|
| GW-001 | 请求路由 | 根据请求路径前缀将请求路由至对应微服务 | P0 | ✅ 已完成 |
| GW-002 | 统一鉴权 | 解析 `satoken` 请求头，验证 Token 有效性 | P0 | ✅ 已完成 |
| GW-003 | 用户身份注入 | 鉴权通过后将 `userId` 注入 `X-User-ID` 请求头 | P0 | ✅ 已完成 |
| GW-004 | 跨域配置（CORS） | 统一配置跨域策略，允许前端跨域访问 | P0 | ✅ 已完成 |
| GW-005 | 白名单放行 | `/login`、`/register` 等接口不经过鉴权 | P0 | ✅ 已完成 |
| GW-006 | 全局异常处理 | 统一处理网关层异常，返回标准格式错误响应 | P1 | 🔄 开发中 |
| GW-007 | 请求日志记录 | 记录每个请求的来源 IP、路径、响应状态码 | P2 | 📋 待开发 |
| GW-008 | 限流（Rate Limiting） | 基于 Redis 实现接口级限流，防止恶意请求 | P2 | 📋 待开发 |

### 2.2 服务注册与配置（Nacos）

| 编号 | 功能名称 | 详细描述 | 优先级 | 状态 |
|------|----------|----------|--------|------|
| NC-001 | 服务注册与发现 | 各微服务启动时注册到 Nacos，支持心跳保活 | P0 | ✅ 已完成 |
| NC-002 | 配置中心集成 | 各服务配置存储于 Nacos，DataID 格式为 `${name}.yaml` | P0 | ✅ 已完成 |
| NC-003 | 配置热更新 | 配置变更后自动推送到各服务，无需重启 | P1 | 📋 待开发 |

## 3. 模块二：用户模块（user-service）

### 3.1 账号管理

| 编号 | 功能名称 | 详细描述 | 优先级 | 状态 |
|------|----------|----------|--------|------|
| US-001 | 用户注册 | 用户通过用户名+密码注册账号，密码 bcrypt 加密存储 | P0 | 🔄 开发中 |
| US-002 | 用户登录 | 用户名+密码登录，颁发 Sa-Token，存储于 Redis | P0 | 🔄 开发中 |
| US-003 | 退出登录 | 清除 Redis 中的 Token，使会话失效 | P0 | 📋 待开发 |
| US-004 | Token 刷新 | 在 Token 即将过期时自动续签，保持用户登录状态 | P1 | 📋 待开发 |
| US-005 | 账号禁用 | 管理员可禁用用户账号，禁用后无法登录 | P2 | 📋 待开发 |
