# Teaching 教学领域

`teaching` 是模块化单体中的教学领域，本身不独立运行。API 契约用于保持模块边界，当前由 `monolith-app` 的进程内适配器实现；所有表统一位于 `monolith_db`。下文旧独立库升级命令仅保留作迁移历史，不用于当前开发。

```text
teaching
├─ teaching-api      模块契约、DTO 与稳定路径常量
└─ teaching-service  教学业务实现，由 monolith-app 统一装配
```

当前已提供：

- 6 张教学业务表及 `teaching_outbox_event` 事务发件箱的 Entity、Mapper 和建表脚本，全库不设置物理外键；
- 教师创建、编辑、归档班级，维护在班学生；学生凭班级码加入和主动退出；
- 教师从内容服务的已发布题库选题，创建统一或分层作业，发布、结束或取消作业；
- 分层发布强制覆盖全部在班学生，发布时冻结题目和学生快照并生成 `ASSIGNED` 提交记录；
- 教师查看学生提交并维护评语，学生查看本人作业、题目和提交状态；
- 教师权限、学生身份、服务间调用和资源归属四层校验；
- 业务写入与审计事件同事务落库，后台确认投递并支持退避重试；
- 作业内部查询契约与 `TeachingFeignClient`，供学习服务后续生成练习任务；
- 权限、状态机、分层规则、数据库映射和可靠审计投递测试。

当前教学服务只负责作业编排与提交汇总。实际答题、自动批改和成绩回写将在学习服务阶段实现。

.\mvnw.cmd -pl teaching -am test
